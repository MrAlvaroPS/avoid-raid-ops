## Production acceptance checks

The deployment is accepted only after:

1. `/api/wcl/corpus?...&action=health` proves Private Vercel Blob access.
2. BUILD 1K returns a `workflowRunId`.
3. The status resolves the live WCL partition before persistence.
4. Progress continues after the browser tab is closed.
5. PAUSE stops progress and RESUME produces a new workflow run while retaining counts.
6. WCL rate-limited state sleeps/resumes without browser stepping.
7. No repeated structural WCL error is allowed past the 3-error circuit breaker.
