# AvoiD Raid Ops v3.6 — Hosted Research Preview

## Why this release exists

The user needs to keep researching for several days before the Mac-based Research Engine is available. v3.6 therefore runs the expensive Encounter Intelligence Pipeline on Vercel **temporarily**, but does so as a durable background workflow rather than a browser-driven chain of short Functions.

## Hosted execution

- Added `workflows/corpus-build.js` using Vercel Workflow.
- API starts a durable run and returns immediately with `workflowRunId`.
- Side-effectful WCL/corpus work remains inside `"use step"` execution.
- The workflow sleeps durably between batches and during WCL rate-limit windows.
- PAUSE revokes the active execution token; RESUME starts a new durable run from the persisted checkpoint.
- Superseded workflow runs stop without continuing corpus work.

## Storage

`server/corpus/storage.mjs` now has two provider adapters behind the same contract:

- Vercel: **Private Vercel Blob**, mandatory in hosted runtime.
- Local development/future Mac runner: filesystem.

Hosted reads use private Blob consistent reads (`useCache:false`) so mutable checkpoint JSON never relies on a stale CDN copy. There is no silent hosted filesystem fallback.

`action=health` performs a real private Blob write/read/delete probe before any corpus build should be started.

## WCL protection

The v3.6 temporary hosted defaults are deliberately conservative:

- 1,000 Wide pulls initial target
- 200 Deep pulls initial target
- maximum target 25,000 pulls
- WCL reserve: max(600 points, 18% of hourly allocation)
- existing 3-identical-structural-error circuit breaker retained

5,000 and 10,000 pull presets remain available in the UI after the 1K validation run succeeds.

## Status payload

The full persisted job can contain thousands of report codes. It is no longer returned to the browser. `/api/wcl/corpus` exposes counts, progress, source diversity, last failure, workflow identity, aggregate/model diagnostics, and rate budget only.

## UI

- Encounter Intelligence Corpus is inserted **before** the mechanic catalogue, directly under the Mechanics banner.
- Browser-driven `POST action=step` loop removed.
- UI polls status every few seconds while the workflow operates independently.
- Closing the tab does not stop the job.
- Presets are 1K / 5K / 10K target pulls.
- Rate-limited state remains pausable; automatic resumption belongs to the workflow.

## Deployment migration

The old raw Vercel Function/static-output configuration is removed. v3.6 uses Vite + Nitro + Workflow integration with zero-config Vercel deployment. Root `index.html` references the immutable Golden production bundle as deferred classic scripts.

## Data truth

No generated model is silently trusted. Until validation/publish gates pass, `/api/wcl/intelligence` continues to identify the encounter knowledge as manual fallback.
