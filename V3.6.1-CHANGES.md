# AvoiD Raid Ops v3.6.2 — changes

## Vercel Workflow build fix

- Fixed the Vercel build failure `Could not resolve "workflow/sleep"`.
- `sleep` is now imported from the public root export: `import { sleep } from "workflow"`.
- Kept Workflow SDK pinned to `4.3.1`, matching the current official Nitro starter generation used by this project.
- Added a regression test that rejects the invalid `workflow/sleep` subpath.

## Composition correctness

- The class representation grid no longer depends on the Golden prototype's 12-row mock list.
- It is rebuilt from the canonical 13 retail classes every time real roster telemetry is applied, including Monk.
- Class dots and bars now use conventional WoW class colours rather than arbitrary prototype colours.
- `Class coverage` and the class grid are derived from the same live roster count map, so they cannot disagree because one uses 12 static rows and the other uses 13 live classes.
- If Monk is truly absent, `Class coverage` explicitly surfaces the raid-utility gap: `Mystic Touch (physical-damage vulnerability)`.
- If WCL reports a Monk, the Monk row will be visible with its real count; this makes any upstream class-normalization issue immediately diagnosable instead of hiding the class.

## Versioning

- Engine/runtime version: `3.6.2`.
- Package version: `0.3.6-1-vercel.1`.
- Golden Master `main.js`, `main.css`, `404.html`, `favicon.svg`, and `og.png` remain untouched.
