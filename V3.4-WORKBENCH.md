# AvoiD Raid Ops — v3.4 workbench

This is a preparation branch for **Belo'ren Intelligence** while v3.3 is being tested.
It is intentionally not wired into visible UX yet. The goal is to let feedback from
v3.3 land without mixing visual fixes with encounter-engine work.

## Implemented in the workbench

- Versioned Belo'ren Mythic rule pack (encounter 3182)
- Light/Void feather state model
- Filtered WCL query plan for encounter mechanics (no all-events firehose)
- Wrong-color damage inference
- Radiant Echoes / Voidlight Rupture failure proxy
- Guardian's Edict boss-empowerment failure rule
- Eruption and Rebirth failure hooks
- Evidence-ranked mechanic failure events
- Mechanical-accuracy derivation from weighted opportunities/failures
- Probable death-chain correlator
- Current Blocker ranking prototype
- Independent `/api/wcl/intelligence` endpoint, behind the existing Golden UI

## Deliberately not enabled in the UI yet

- Reliability
- Kill Readiness
- prescriptive Next Pull calls
- preventable-death claims
- defensive-ready claims

Those will only be enabled after the real endpoint has been validated against the
Avoid report and after v3.3 UI feedback has been merged.

## Key safety property

The Golden Master UI and v3.3 runtime are untouched by the new intelligence code.
The workbench only adds new engine/query/rule-pack files and one isolated endpoint.
