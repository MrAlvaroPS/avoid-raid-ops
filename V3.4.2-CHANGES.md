# AvoiD Raid Ops v3.4.2 — changes

## 1. Analytical pull population

Called-wipe/reset fights now receive a first-class eligibility verdict with
classification, reasons and evidence. They remain visible to WCL/history but are
removed from:

- pull-to-pull comparisons
- progression baselines
- mechanic scoring
- blocker ranking
- Reliability inputs
- throughput directional comparisons

LIVE compares the latest pull to the previous analytical pull and explicitly
states when one or more raw resets were skipped.

## 2. Belo'ren Rebirth split

`1241313` is represented as the boss's normal Rebirth/intermission and is
observational only. `1263412` is the scoreable Ember Rebirth failure signal.
Boss Rebirth can therefore never inflate Ember failures or become the current
blocker.

## 3. Feather assignment ingestion

Light/VOID assignment ingestion is narrowed to:

- Light Feather `1241162`
- Void Feather `1241163`

Buff and Debuff event streams are paginated independently and deduplicated. The
mechanics engine rebuilds the colour timeline per fight so assignments cannot
bleed across pulls.

## 4. Occurrence-normalized mechanics

Mechanic aggregates now expose separate concepts:

- `opportunities`: mechanic executions observed
- `failedOccurrences`: failed executions
- `playerExposures`: distinct affected-player evidence
- `cleanOccurrences`
- `executionSuccessPct`
- `denominatorStatus`

Five players affected by one Dive can therefore produce one failed execution and
five exposures, never five failed executions.

## 5. Quill splash safety

Mythic Infused Quill damage is treated as an observed splash impact. Damage
recipients are not scored as failed interceptors because the damage event alone
does not identify the direct interceptor.

## 6. Guardian's Edict

The boss empowerment aura is the confirmed failed-execution signal. Duplicate
aura rows around the same execution collapse to one failed occurrence.

## 7. Flames and Radiant Echoes

- Flames require periodic wrong-colour evidence; a normal direct hit alone is
  not a failure.
- Voidlight Rupture evidence is grouped into player episodes and then mapped to
  a mechanic occurrence instead of counting every tick.

## 8. Mechanical Accuracy

Mechanical Accuracy is calculated only when all active scoreable mechanics have
valid normalized denominators. Otherwise the UI displays PENDING rather than a
misleading score.

## 9. Talent display hardening

Literal placeholders (`Spell null`, `Spell undefined`, raw `Node ####`, raw
`Entry ####`) are sanitized in both backend normalization and frontend display.
When WCL supplies a canonical talent import code, Composition links the exact
build to Wowhead instead of inventing talent names.

## 10. Source/deployment continuity

The same package contains the backend/domain source, source-owned React tree,
Golden compatibility frontend, tests and Netlify configuration. Git-based
Netlify deployment can use the active `netlify.toml` without switching to the
source-built UI.
