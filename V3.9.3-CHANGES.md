# v3.9.3 — Provider-aware Ability & Encounter Knowledge

## Scope

Backend/knowledge release on top of v3.9.2. Players/Reliability browser ownership remains v3.9.2.

## Added

- Fingerprinted `/api/knowledge/ability` preview/resolve contract.
- Bounded read-only Lorrgs client for boss spell membership and spell metadata.
- Optional Parse-maintained Wowhead wrapper client, server-keyed with explicit credit confirmation.
- Optional WCL GameData/WorldData static metadata lookup batched into one GraphQL request for up to 20 abilities.
- Provider disagreement and encounter-association normalization.
- `iris-source-registry-v2` and Iris capability release 3.9.3.
- Documentation for provider-aware knowledge and Parse/Wowhead API possibilities.

## Evidence invariants

Provider metadata is enrichment only. WCL observed combat remains canonical. This release adds 0 canonical Deep reports/pulls, 0 direct score delta and no automatic mechanic promotion.
