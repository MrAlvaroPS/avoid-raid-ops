# v3.6.3 verification

The change is intentionally narrow: remove the Vercel/Nitro double-compilation trigger while keeping endpoint URLs and domain logic unchanged.

Checks run before packaging:

- Golden Master integrity
- architecture verification
- source reconstruction verification
- unit tests
- Data Truth verification
- Node syntax checks for Workflow and all Nitro routes
- explicit regression check that no top-level `api/` source directory exists

The production Vercel build remains the final integration test because this environment cannot reproduce Vercel's own post-build packaging stage.
