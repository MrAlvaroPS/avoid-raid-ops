# AvoiD Raid Ops v3.4 — Belo'ren Intelligence

## Operational intelligence

A new `/api/wcl/intelligence` endpoint runs the encounter rule pack independently
from the core report/telemetry/history APIs.

For Belo'ren it classifies supported WCL evidence for:
- Light/Void assignment mismatches
- Light/Void Dive
- Light/Void Quills
- Radiant Echoes / Voidlight Rupture proxy
- Guardian's Edict boss empowerment
- Light/Void Eruption
- Ember Rebirth
- Light/Void Flames
- additional observed pressure mechanics

It returns:
- mechanic opportunities/failures
- player failure matrix
- meaningful death chains
- Current Blocker ranking
- latest-pull evidence
- up to three evidence-backed next-pull calls

## LIVE

Roster Intelligence is Composition-only. LIVE contains only information that can
change decisions during the current raid night:
- latest closed pull
- pull-vs-pull gains/regressions
- current blocker
- latest-pull classified mechanic evidence
- death-linked evidence
- next-pull calls

## Composition talents

WCL CombatantInfo may expose TraitNodeEntry/node IDs without a trustworthy talent
name or spell ID. v3.4 no longer shows strings such as `Node 82126`.

Resolved talent names/spell IDs may still be displayed and linked to Wowhead.
Unresolved raw node IDs stay internal and the UI shows an explicit unavailable
state instead.

## Data truth

The Golden Master still exists as an immutable visual reference, but production
surfaces may display only:
- observed real WCL data
- derived metrics with evidence
- PENDING/N/A

No Golden mock metric is allowed to survive visibly.
