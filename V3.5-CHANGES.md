# AvoiD Raid Ops v3.5 — Encounter Intelligence Pipeline

v3.5 changes the encounter-analysis architecture from "hand-code every boss" to "compile a versioned encounter model from a large Warcraft Logs corpus".

## Main changes

- New persistent **Encounter Intelligence Corpus** pipeline.
- Default corpus target: **2,500 ranked public reports**. UI presets: 2,500 / 5,000 / 10,000.
- Two-tier sampling:
  - **wide corpus**: low-cost WCL summary tables across thousands of reports;
  - **deep sample**: full event/state analysis across 12% of the corpus (default 300, capped at 1,000).
- Ranked kill reports are used as entry points, then the report's wipes + kills for the same encounter/difficulty are retained. The statistical unit is therefore thousands of reports and potentially many more pulls.
- Deterministic **80/20 training/holdout split** by report code.
- Generated mechanics are validated on reports not used for training.
- Models do not become runtime truth merely because they compile. Auto-publish requires, by default:
  - >= 1,500 wide reports;
  - >= 200 deep reports;
  - >= 250 holdout reports;
  - at least one accepted mechanic;
  - >= 66% mean holdout validation score across accepted mechanics.
- Existing curated encounter pack remains a fallback until the generated model clears publication gates.
- Generated model becomes the preferred runtime encounter pack automatically after publication.
- Persistent checkpointing through **Netlify Blobs**. Deploys do not erase the corpus.
- `ENRICH +500` adds new reports later in the season without re-fetching/reprocessing already profiled reports.
- WCL rate budget protection pauses automatically and resumes from the saved checkpoint.
- Deep inference ignores truncated event streams rather than learning from incomplete denominators.
- Current/default WCL partition is recorded; enrichment refuses to silently mix data if the default partition changes.
- Generic state-pair discovery added (e.g. Light/Void-like mutually exclusive states) using lexical candidates plus event-backed exclusivity.
- Generic mechanic signatures include interrupt, phase transition, raid damage, dangerous completed cast, avoidable damage and wrong-state impact.
- v3.4.2 `wipeCalledTime=0` bug fixed: WCL zero now means "unset", not "called wipe at pull start".

## UI

The Mechanics screen now includes an additive `Encounter Intelligence Corpus` workbench with:

- corpus target selector (2.5k / 5k / 10k);
- wide/deep progress;
- retained pull count;
- model publication status and holdout score;
- WCL rate budget;
- build / pause / resume / enrich / refresh controls.

The original Golden Master assets remain untouched.
